# סוליטר מילים

משחק קלפים בדפדפן. על כל קלף כתובה מילה.

## החפיסה

עשר קטגוריות, ובכל אחת מספר אחר של מילים — שלוש עד שמונה, חמישים ושלוש מילים בסך הכול.
לכל קטגוריה יש גם קלף שם, שלצדו רשום מספר המילים שבה. יחד שישים ושלושה קלפים.

## החוקים

- בלוח שמונה ערמות, בגדלים אחד עד שמונה. בכל ערמה חשוף בתחילה רק הקלף העליון, וקלף שנחשף נשאר גלוי, כך שנראות כותרות כל הקלפים הגלויים.
- שאר הקלפים יושבים הפוכים בחפיסה שלמעלה. לחיצה עליה חושפת קלף אל ערמת הגלויים שלצדה, והוא מכסה את הקלף שנחשף לפניו. זמין לשימוש רק העליון שבגלויים. כשהחפיסה מתרוקנת, הלחיצה הבאה מחזירה אליה את הגלויים ומתחילה סיבוב נוסף.
- ארבעה מקומות פנויים למעלה מקבלים רק קלף שם של קטגוריה.
- על קלף שם מניחים רק מילים מאותה קטגוריה.
- על מילה אפשר להניח מילה אחרת מאותה קטגוריה, בין למעלה ובין בלוח.
- רצף של קלפים גלויים בערמה הוא תמיד מקטגוריה אחת, ואפשר להעביר אותו בשלמותו.
- ערמה בלוח שהתרוקנה פנויה לכל קלף או רצף.
- קטגוריה שהושלמה יורדת מהלוח, והמקום מתפנה לקטגוריה הבאה.
- המטרה לרוקן את הלוח כולו.

גוררים קלף אל היעד, או מקישים על קלף ואחר כך על היעד.
ניסיון להניח קלף במקום שאינו חוקי מרעיד את הלוח ומשמיע צליל, ואפשר לכבות את הצליל בכפתור.
המשחק סופר מהלכים, זמן, וטעויות. חשיפת קלף מהחפיסה נספרת כמהלך.

## חלוקה פתירה

כל חלוקה נבדקת לפני שהיא מוצגת: המשחק מריץ עליה משחקי ניסוי אוטומטיים,
ומחלק מחדש עד שהוא מוצא חלוקה שיש לה פתרון. כשישים אחוז מהחלוקות עוברות
את הבדיקה, כך שדי בדרך כלל בחלוקה אחת או שתיים. הבדיקה מתעלמת משני מהלכים
שרק מקלים — העברת רצף שלם והנחה בערמה שהתרוקנה — ולכן היא חסם מלמטה:
חלוקה שעברה אותה פתירה בוודאות גם עם המהלכים האלה.
