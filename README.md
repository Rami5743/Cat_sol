# סוליטר מילים

משחק קלפים בדפדפן. על כל קלף כתובה מילה.

## החפיסה

עשר קטגוריות, ובכל אחת מספר אחר של מילים — שלוש עד שמונה, חמישים ושלוש מילים בסך הכול.
לכל קטגוריה יש גם קלף שם, שעליו רשום מספר המילים שבה. יחד שישים ושלושה קלפים.

## החוקים

- הקלפים מחולקים לתשע ערמות בגודל שונה, ובכל ערמה חשוף רק הקלף העליון.
- למעלה ארבעה מקומות פנויים, ואליהם אפשר להעביר רק קלף שם של קטגוריה.
- על קלף שם מניחים רק מילים מאותה קטגוריה.
- על מילה אפשר להניח מילה אחרת מאותה קטגוריה, בין למעלה ובין בלוח.
- לצד המקומות הפנויים יש ערמת המתנה שאליה אפשר להעביר כל קלף, אך זמין בה רק הקלף העליון.
- קטגוריה שהושלמה יורדת מהלוח, והמקום מתפנה לקטגוריה הבאה.
- המטרה לרוקן את הלוח כולו.

המשחק סופר מהלכים, זמן, וטעויות — ניסיונות להניח קלף במקום שאינו חוקי.

## חלוקה פתירה

כל חלוקה נבדקת לפני שהיא מוצגת: המשחק מריץ עליה משחקי ניסוי אוטומטיים,
ומחלק מחדש עד שהוא מוצא חלוקה שיש לה פתרון.
